Compliance

Data handling, retention, and processing commitments.

Data residency

Atlas can be deployed in your infrastructure or cloud tenant. Data is stored in the region you specify. No cross-region data transfer occurs without explicit configuration.

Data retention

Claims, conflicts, and reports are immutable by design — they are never deleted, only superseded. Ingestion runs, raw snapshots, and activity logs are retained per your retention policy. Session data is swept every 10 minutes.

Data processing

Atlas processes aviation accident data from public sources (NTSB, FAA) and your organization's private data. Public data is indexed and searchable. Private tenant data is isolated by PostgreSQL Row-Level Security and never exposed to other tenants or public endpoints.

Subprocessors

Atlas uses the following subprocessors for infrastructure:

  • Cloud infrastructure — your chosen provider (AWS, GCP, Azure, or on-premises)
  • Database — PostgreSQL/PostGIS
  • Object storage — S3-compatible (MinIO, AWS S3, or equivalent)
  • LLM inference — your choice of provider; no training data is collected from API calls
