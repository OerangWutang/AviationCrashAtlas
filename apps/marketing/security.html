Security

Defense-in-depth for sensitive investigation data.

API key safety

Atlas API keys are bearer credentials that encode role and tenant identity. They are stored hashed (HMAC-SHA256) and never transmitted to the browser. The Backend-for-Frontend (BFF) proxies authenticated requests using server-side keys encrypted with AES-256-GCM.

Authentication & authorization

Session security

HttpOnly, Secure, SameSite=Lax session cookies. CSRF protection via double-submit cookie pattern.

Role-based access

Analyst (read-only), Reviewer (resolve conflicts, upload documents), Admin (system operations). Enforced server-side and at the database level.

Audit trail

Every conflict resolution, report generation, and ingestion action is recorded with actor identity and timestamp.

Rate limiting

Login attempts are rate-limited per IP. API endpoints have configurable rate thresholds.

Infrastructure security

  • PostgreSQL Row-Level Security for tenant data isolation
  • All API traffic over HTTPS (TLS 1.3)
  • Request body size limits and HSTS headers
  • TrustedHost enforcement in production
  • Dependency vulnerability scanning in CI pipeline
